Why Use Font Switcher?

Designed for Indigenous Script Preservation

Empower your readers to view traditional Nepal Lipi and Ranjana scripts without breaking standard web accessibility or search indexing.

4 Supported Font Modes

Seamlessly switch between Original Devanagari, Nithya Ranjana webfont, Nepal Lipi Aakha, and official Google Noto Sans Newa Unicode.

Instant Unicode Conversion

Automatically converts standard Devanagari text into official Unicode 9.0 Newa script block characters when selecting Noto Sans Newa.

Dark Mode & Contrast Ready

Automatically detects dark background colors and applies contrast adjustment so dropdown text remains readable everywhere.

Zero External Dependencies

Written in vanilla JavaScript and CSS. Lightweight (~5KB), zero frameworks required, works on all modern mobile and desktop browsers.

Persistent Preference

Remembers the user's selected font preference using localStorage so their choice persists seamlessly across page navigations.

Flexible Placement

Place the widget anywhere: inside a navigation bar, header element, sidebar container, or let it float freely in the top-right corner.

Developer Guide

Quick Start & Configuration Reference

Complete overview of parameters for FontSwitcher.init() options.

Option Type Default Description
targetClasses Array null Array of class names (e.g. ['newa-content', 'article']) to apply font switching to. Takes precedence over targetSelector.
targetSelector String 'body' CSS selector string for elements to apply font switching when targetClasses is not set.
container String | HTMLElement null CSS selector or DOM element where widget is inserted. If null, floats fixed in top-right.
backgroundColor String null Custom background color hex/rgb/name. Auto-adjusts text color for dark backgrounds.
autoLoad Boolean true Automatically loads Google Fonts stylesheet for Noto Sans Newa when selected.
storageKey String 'font-switcher-selection' localStorage key for saving user preference.
